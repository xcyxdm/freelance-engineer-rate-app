# Freelance Engineer Interview Report

フリーエンジニアの面談レポートを登録・管理する Spring Boot アプリです。

## 構成

- Spring Boot 3
- PostgreSQL
- Docker Compose
- Flyway
- Thymeleaf

## 起動

```bash
docker compose up
```

起動後、ブラウザで次を開きます。

```text
http://localhost:8081
```

## できること

- 面談レポートの一覧表示
- 新規登録
- 詳細表示
- 編集
- 削除

## 登録項目

- 会社
- 年齢
- 職種
- 単価
- 案件概要
- 結果
