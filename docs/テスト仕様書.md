# フリーエンジニア ポートフォリオサイト テスト仕様書

## 1. テスト目的

本テストは、ポートフォリオサイト、問い合わせフォーム、フリーエンジニア相場データ管理機能が仕様どおり動作することを確認するために実施します。

## 2. テスト対象

- トップページ
- 個人履歴ページ
- 問い合わせフォーム
- フリーエンジニア相場データ画面
- 面談レポート登録・詳細・編集・削除
- 検索・統計表示
- Docker Compose起動
- メール送信

## 3. テスト環境

| 区分 | 内容 |
| --- | --- |
| OS | Windows、Ubuntu on AWS Lightsail |
| ブラウザ | Microsoft Edge、Google Chrome |
| アプリ | Spring Boot 3.3.5 |
| DB | PostgreSQL 16 |
| コンテナ | Docker Compose |
| メール | Yahoo SMTP |

## 15. テスト実行時の注意

- CSS変更後に画面が変わらない場合は、ブラウザで `Ctrl + F5` を実行します。
- AWSでログを確認する場合は、以下を実行します。

```bash
docker compose logs -f app
```

- メール送信テスト後、DEBUGログ設定は通常運用では外します。
