3. Docker構成
docker-compose.yml では2つのサービスを定義した。

db:
- image: postgres:16-alpine
- container_name: interview-report-db
- DB名: interview_reports
- ユーザー: app
- パスワード: app_password
- ポート: 5432:5432
- volume: postgres_data

app:
- build: .
- container_name: interview-report-app
- DBがhealthyになってから起動
- 環境変数でDB接続先を指定
- ポート: 8081:8080

ブラウザURL:
http://localhost:8081

4. Docker起動時の対応
最初に localhost:8080 を開くと EDB/Postgres の別サービスが表示されたため、アプリ側のホストポートを8081に変更した。

変更:
docker-compose.yml
ports:
  - "8081:8080"

5. Docker Desktop関連の説明

  - docker compose up --build を再実行

6. Dockerの場所について説明
- Docker Desktopアプリ本体は、ユーザー環境では以下にあった。
  C:\Users\jyo\AppData\Local\Programs\DockerDesktop
- Dockerの実データ、イメージ、コンテナ、volumeはWSL2側に置かれることがある。
- \\wsl$\ はWindowsからWSLのLinuxファイルシステムを見る特殊パス。
- PostgreSQLのvolumeはDocker内部にあり、通常は直接編集しない方がよい。

8. eclipse-temurin:21-jreについて
- Spring Bootアプリを実行するためのJava 21実行環境。
- Dockerfileでは2段階ビルドにした。

ビルド用:
maven:3.9.9-eclipse-temurin-21

実行用:
eclipse-temurin:21-jre

Spring Bootアプリは内蔵Tomcatを含むjarとして作られ、java -jar app.jar で起動する。
そのため、TomcatイメージではなくJava実行環境の eclipse-temurin:21-jre を使う。

9. eclipse-temurin:21-jre の代替
代替候補:
- amazoncorretto:21
- azul/zulu-openjdk:21-jre
- ibm-semeru-runtimes:open-21-jre
- bellsoft/liberica-openjre-alpine:21
- openjdk:21-jdk

ただし、特別な理由がなければ eclipse-temurin:21-jre のままでよいと説明した。

14. テストについて
src/test のJavaは、Spring Bootアプリが最低限起動できるか確認するための自動テスト。

主なファイル:
src/test/java/com/example/interviewreport/InterviewReportApplicationTests.java

役割:
- Spring Boot設定が壊れていないか確認
- EntityやRepository設定が致命的に間違っていないか確認
- テスト用DB設定で起動できるか確認

実行方法:
mvn test

Dockerだけで実行する場合:
docker run --rm -v "%cd%:/workspace" -w /workspace maven:3.9.9-eclipse-temurin-21 mvn test
