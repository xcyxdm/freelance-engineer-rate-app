# フリーエンジニア ポートフォリオサイト 仕様書

## 1. システム概要

本システムは、フリーエンジニア向けの個人ポートフォリオサイトです。
トップページ、個人履歴ページ、開発サンプルへのリンク、問い合わせフォームを提供します。

開発サンプルとして、フリーエンジニア相場データ管理機能を同一アプリ内に持ちます。
相場データ管理では、面談レポートの登録、一覧表示、詳細表示、編集、削除、検索、統計表示を行います。

## 2. 利用者

- サイト閲覧者
- 開発案件の相談者
- 管理者または登録作業者

## 3. システム構成

| 区分 | 内容 |
| --- | --- |
| アプリケーション | Spring Boot 3.3.5 |
| 画面 | Thymeleaf |
| データベース | PostgreSQL 16 |
| DBマイグレーション | Flyway |
| メール送信 | Spring Mail、Yahoo SMTP |
| コンテナ | Docker / Docker Compose |
| 実行Java | Eclipse Temurin 21 JRE |
| 配置先 | AWS Lightsail |
| バージョン管理 | Git / GitHub |

## 5. トップページ仕様

### 5.1 表示内容

- サイトタイトル
- フリーエンジニアとしての紹介文
- 主催者の個人履歴へのリンク
- 開発案件相談受付の案内
- 問い合わせフォームへのリンク
- できることの紹介
  - 業務理解
  - バックエンド開発
  - クラウド対応
  - AI活用
- プロジェクトのサンプル

### 5.2 プロジェクトサンプル

| No | 名称 | リンク |
| --- | --- | --- |
| 1 | フリーエンジニア相場データ | `/rates` |
| 2 | フリーランスエンジニア掲示板 | 外部掲示板アプリ |

### 5.3 利用ルール

サンプルは自由に利用できます。
ただし、誹謗中傷、個人情報の投稿、著作権など第三者の権利を侵害する内容の投稿は禁止します。

## 6. 個人履歴ページ仕様

### 6.1 表示内容

- プロフィール
  - 職種
  - 業界経験
  - 得意分野
  - 資格
- できるスキル
  - 言語 / フレームワーク
  - DB
  - インフラ / ツール
  - 担当工程
- 職務経歴

### 6.2 非表示項目

職務経歴の期間列はHTML上に保持しますが、画面では表示しません。

### 6.3 匿名化方針

公開ページであるため、職務経歴の企業名やプロジェクト名は必要に応じて匿名化します。

例:

| 元の表現 | 公開用表現 |
| --- | --- |
| 日通グローバル倉庫管理システム（NX-GLOW） | 大手運送会社グローバル倉庫管理システム |
| 第一生命 保険金サブシステム | 大手生命保険会社 保険金サブシステム |
| 北里研究所 社内SE | 大学研究所 社内SE |
| IBM DB2製品 テクニカルサポート | ブランドデータベース製品のテクニカルサポート |

## 7. 問い合わせフォーム仕様

### 7.1 入力項目

| 項目 | 必須 | 入力制限 |
| --- | --- | --- |
| お名前 | 必須 | 100文字以内 |
| メールアドレス | 必須 | メール形式、255文字以内 |
| お問い合わせ内容 | 必須 | 2000文字以内 |

### 7.2 送信処理

フォーム送信時、入力チェックを行います。
入力エラーがある場合は、問い合わせ画面にエラーメッセージを表示します。

入力が正常な場合、Yahoo SMTPを使用して問い合わせメールを送信します。
送信後は問い合わせ画面へリダイレクトし、「お問い合わせを受け付けました。」を表示します。

### 7.3 メール送信先

環境変数 `CONTACT_TO` に設定されたメールアドレスへ送信します。

### 7.4 メール設定

| 設定 | 値 |
| --- | --- |
| SMTPホスト | `smtp.mail.yahoo.co.jp` |
| SMTPポート | `465` |
| SSL | 有効 |
| SMTP認証 | 有効 |

メールユーザー名とパスワードは環境変数で指定します。
ソースコードやGitHubにはパスワードを保存しません。

## 8. フリーエンジニア相場データ仕様

### 8.1 機能一覧

- 面談レポート一覧表示
- 面談レポート新規登録
- 面談レポート詳細表示
- 面談レポート編集
- 面談レポート削除
- 年齢別検索
- 勤務形態別検索
- 職種別検索
- 年齢別統計
- 勤務形態別統計
- 職種別統計
- 平均単価表示

### 8.2 登録項目

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 会社 | 任意 | 120文字以内 |
| 年齢 | 必須 | 18歳以上、80歳以下 |
| 職種 | 必須 | リストから選択 |
| 単価 | 必須 | 5万円以上、999万円以下、5万円刻み |
| 勤務形態 | 必須 | フルリモート、部分リモート、フル出勤 |
| 契約形態 | 必須 | 業務委託、契約社員、派遣 |
| 案件概要 | 任意 | 自由入力 |
| 担当役割 | 必須 | PM、PMO、リーダー、SE、PG |

### 8.3 職種選択肢

- SE・プログラマ・開発エンジニア
- ネットワーク・サーバーエンジニア
- セキュリティエンジニア
- PMO・SEアシスタント
- テストエンジニア（評価・検証）
- ヘルプデスク・テクニカルサポート・OAインストラクター
- FAE・セールスエンジニア・プリセールス
- AIエンジニア・データサイエンティスト

### 8.4 検索条件

| 条件 | 内容 |
| --- | --- |
| 年齢別 | 20代、30代、40代、50代、60代以上 |
| 勤務形態別 | フルリモート、部分リモート、フル出勤 |
| 職種別 | 職種選択肢から選択 |

### 8.5 統計表示

検索結果を対象として以下を表示します。

- 検索結果件数
- 平均単価
- 年齢別件数
- 勤務形態別件数
- 職種別件数

## 11. 起動方法

Docker Composeで起動します。

```bash
docker compose up --build -d
```

ローカル環境で確認する場合は、設定された公開ポートにアクセスします。
AWS Lightsailでは公開URLからアクセスします。

## 12. 補足

問い合わせフォームはメール送信を行いますが、問い合わせ内容のDB保存は行いません。
メール送信の詳細ログは通常運用ではDEBUGにしないでください。
